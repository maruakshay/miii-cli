Built-in tool suite

A real agent, not a chat box.

miii decomposes problems, invokes tools autonomously, and verifies its own work — gated by a permission system you control.

📖

Reads & writes code

read_file, write_file, edit_file — precise string-level edits with whitespace tolerance, no blind rewrites.

🔎

Searches your repo

glob + grep with context, type filters, multiline and count modes across the whole project.

⚡

Runs your shell

run_bash executes commands and tests, so the agent verifies outcomes instead of guessing.

🔒

Permission-gated

Every sensitive op is approved by you. "Always" rules persist to ~/.miii/permissions.json. File tools are confined to your workspace.

🧾

Lossless output spill

Huge tool outputs aren't truncated — they spill to disk with a head+tail preview, and the model pages the middle on demand.

🩺

Model doctor

miii doctor validates your local models against real engineering tasks and tells you which can actually drive the agent.

Quick start

Three commands to a local agent.

Requires Node.js ≥ 18 and Ollama running locally.

1 Pull a model

# any coding model works
ollama pull qwen2.5-coder:14b

2 Install miii

npm install -g miii-agent

3 Run it

miii

# then just talk to it
> @src/server.ts add rate limiting
> why are my tests failing?
