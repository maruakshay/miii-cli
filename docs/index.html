    Questions.

    Is miii really free?

    Yes. miii is MIT-licensed with no paid tier, no account and no sign-up. With a local model you pay nothing at all.

    Is my code ever uploaded?

    With a local provider, your code only ever travels to localhost. No telemetry and no analytics — the one outbound call miii makes on its own is a version check against registry.npmjs.org, which carries nothing but the package name.

    Can it break my repo?

    Every write and every shell command asks first, and file tools are confined to the working directory. When something does go wrong, /rewind puts the files and the conversation back.

    Is there a desktop or web app?

    Yes — run miii web in any project and it opens in your browser: a chat sidebar, streaming replies, real diffs and one-click approvals. It's the same agent and sessions as the terminal, served only on localhost, and every request needs the key in the link it prints.

    Do I need a GPU?

    For fully local models you want one — qwen2.5-coder:3b runs on CPU, but it will be slow and need more hand-holding. Apple Silicon works well: unified memory counts as VRAM here.

    Why not just use Claude Code or Cursor?

    Use them if you can. miii is for when you want the same workflow without being tied to one vendor or one subscription — or you need to go fully offline for air-gapped work, NDA'd code, or a flight with no wifi.
